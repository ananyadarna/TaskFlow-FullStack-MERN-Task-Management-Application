# TaskFlow - Full-Stack MERN Task Management Application

Production-ready MERN stack Task Management application featuring JWT authentication, user-isolated task CRUD, filtering & pagination, file attachments via Cloudinary, email notifications via Nodemailer, and live weather via OpenWeatherMap API.

## Project Structure
- `backend/`: Node.js + Express.js API server
- `frontend/`: React + Vite + Tailwind CSS dashboard
